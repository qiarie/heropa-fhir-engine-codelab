Manage FHIR resources using the Kotlin FHIR Engine

This guide takes you through the codelab on the Heropa lab, where you write the code in an editor in your browser and the app runs as a web page. A FHIR server for the app to talk to is already running in your lab. You install nothing.

It is built on the published codelab, which was written for Android Studio on your own computer. This guide covers the lab only. If you would rather work in Android Studio, follow the published codelab instead of this guide.

The codelab text comes from the Kotlin FHIR Engine project under codelabs directory and is used under the Apache License 2.0.
