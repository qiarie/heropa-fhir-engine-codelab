7. Search for patients by name

In this step, you'll filter the patient list by the name typed in the search field.

Find the // 7 Replace with code from the codelab to search for patients by name. comment in searchPatientsByName and replace it with the following code:

// 7 Search for patients by name
showPatients {
  fhirEngine
    .search<Patient> {
      if (nameQuery.isNotEmpty()) {
        filter(
          StringClientParam("name"),
          {
            modifier = StringFilterModifier.CONTAINS
            value = nameQuery
          },
        )
      }
    }
    .map { it.resource }
}

The comment is in PatientListViewModel.kt, inside the searchPatientsByName function at the end of the file. Press Ctrl+F, or Cmd+F on a Mac, and type // 7 to jump to it, and replace that one line with the block above. This step needs no new import, because StringFilterModifier came in with step 6. Save the file and wait for BUILD OK.

Here, if nameQuery is not empty, the search returns only the patients whose names contain it. showPatients, which is already in the starter, shows the result. Each letter you type starts a new search, so showPatients cancels the previous search first. Otherwise an older search, such as the one for the first letter, could finish last and replace the result.

Run your app again. You should now be able to enter a name, or part of a name, in the search field to filter the list of patients.

On the lab, click in the Search by name field of the App preview tab and type Abby. The list shrinks to the one patient with that name. The search reads the database in your browser and sends nothing to the server, so nothing new appears in the Output tab.

If you would rather jump to the finished code, type step 7 in the Terminal tab.
